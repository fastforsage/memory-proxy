## Found and fixed by the live run and the template regression
1. The warm-up was sent without `tools` → for every template that renders tools at the beginning, the warmed prefix did not match (the cache was lost).
2. Fact extraction without `max_tokens`: a small model in JSON mode looped and held the only slot for 300 s → the user got 502. Now `EXTRACT_MAX_TOKENS` and extraction through the BackgroundGate.
3. Recall attached the same fragments to every question because of common words (+300 tokens per turn). Now only words the model does not see, a snippet around the match, no repeats.
4. Reserving the epoch head "at the maximum" shrank the window to one turn with a small budget → the epoch changed every turn. Now it uses the actual size.
5. A garbage summary ("0") was accepted → now a fallback.
6. `COMPRESS_AT=0` with an unknown limit gave a budget of 256.
7. The CI smoke test expected `ci-user` in `/facts`; in single mode it is `default`.
