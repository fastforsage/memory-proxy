# UX-тесты v5.0.0 → v5.0.1

**Русский** | [English](../en/audit/v5.0.1-ux.md)

Что видит человек, который ставит memory-proxy и пользуется им каждый день: подключение клиента, ошибки, память, команды, служебные запросы клиентов, перегенерация, падения модели, `manage.py`. Всё, что найдено, исправлено в v5.0.1.

## Как проверяли

- **Бэкенд:** llama.cpp `llama-server` b12812, `-c 4096 -np 1 -t 2 --jinja`. Модели — Qwen2.5-0.5B-Instruct Q4 (основной прогон) и Qwen2.5-1.5B-Instruct Q4 (проверка извлечения фактов). Машина — 2 CPU, 2 ГБ RAM, без GPU.
- **Прокси:** из исходников, `API_KEY=sk-test`, штатная модель эмбеддингов USER2-small.
- **Клиенты:** скрипт-зонд на `httpx` и официальном OpenAI SDK. Он воспроизводит запросы Open WebUI (служебные шаблоны взяты из исходников Open WebUI main: заголовок, теги, подсказки, поисковый запрос, автодополнение, emoji, MoA, выбор инструмента), SillyTavern (system + примеры + имена, служебное саммари), агента с `tools` (Cline/Continue) и сообщение с картинкой.
- **Сбои:** бэкенд выключен; фейковый бэкенд, который рвёт стрим после двух чанков и отдаёт обрезанный JSON без стрима.
- **Сценарии:** первое подключение, обычный чат, SDK, «рассказал о себе → вспомнил в новом чате → забыл», реальный поток Open WebUI (ответ → заголовок/теги/подсказки → `/facts` → следующий вопрос), все слэш-команды, продолжение после команды, ошибки, перегенерация и правка, SillyTavern, агент, картинка, `manage.py`, бэкенд недоступен.

## Находки

| # | Что видел пользователь | Причина | Исправление |
|---|---|---|---|
| B1 | Неверный ключ, битый JSON, кривой `messages` → `{"detail": "…"}`; OpenAI SDK и клиенты показывают «Unknown error» | Ответы FastAPI по умолчанию | Все ошибки — `{"error": {"message", "type", "code"}}`, `detail` оставлен для совместимости |
| B2 | Открыл прокси по IP из локальной сети → `Invalid host header`, непонятно, что делать | `TrustedHostMiddleware` | JSON-ошибка с подсказкой про `ALLOWED_HOSTS`; в лог — какое имя добавить |
| B3 | POST без `Content-Type: application/json` → невнятная ошибка | — | 415 в формате OpenAI |
| B7 | Слишком длинное сообщение → 400 без лимита | — | 413, в тексте длина и `MAX_INPUT_LEN` |
| — | Модель не запущена → 500 и трейсбэк в логе прокси, у клиента «Internal Server Error» | Исключение `httpx` не обрабатывалось | 502 `backend_unavailable` / 504 `backend_timeout` с адресом и подсказкой про `LLAMA_URL`; так же `/v1/models` |
| B4 | `/fact` (без s) уходил в модель, она отвечала что-то своё | — | «❓ Команды /fact нет. Возможно, /facts?» (difflib, порог 0.75; с аргументами — 0.85). Точные команды с текстом (`/help me write…`) и чужие (`/imagine`, `/etc/hosts`) по-прежнему уходят в модель |
| **B5** | **Рассказал о себе — `/facts` пуст. В Open WebUI факты не сохранялись никогда** | (a) После каждого ответа Open WebUI шлёт 2–3 служебных запроса; каждый вытеснял фоновое извлечение, после 4 попыток оно бросалось. (b) Промпт-схема с заглушками и списком через запятую: Qwen 0.5B/1.5B возвращали заглушки, выдуманные предикаты и перефразированные цитаты, проверка всё отбрасывала. (c) Если модель называла сообщение «technical», терялись и личные факты | (a) Повтор до `COLD_RETRY_S` (30 мин), команды фон не трогают. (b) Новый промпт: предикаты с описаниями, правила, пример; синонимы предикатов; нечёткое совпадение цитаты; счётчики отказов в логе. (c) Факты от первого лица сохраняются и тогда. A/B на Qwen2.5-1.5B, 10 типичных сообщений: **1 → 15** верных фактов |
| B6 | Запросы Open WebUI «подбери emoji», MoA и выбор инструмента сохранялись в историю и шли на извлечение фактов | Не было в списке служебных шаблонов | Добавлены; system-промпт одиночного запроса тоже проверяется (`SERVICE_SYSTEM_PATTERNS`) |
| B8 | Перегенерация → в истории два ответа на один вопрос, в примерах стиля — отвергнутый | Новый ответ дописывался | Заменяет прежний ответ, прежний пример стиля удаляется |
| B9 | Бэкенд упал посреди ответа → стрим просто обрывался (curl rc=18), клиент не знал, что ответ неполный; обрывок сохранялся как ответ | Исключение в генераторе стрима | SSE-событие `error` (`backend_stream_error`) и `[DONE]`; обрывок не сохраняется |

### Найдено при перепроверке исправлений

| # | Что | Исправление |
|---|---|---|
| R1 | **Петля примеров стиля.** 0.5B один раз ответила «Как искусственный интеллект, я не имею…», ответ стал примером стиля, модель стала копировать его на любой вопрос, а каждая копия снова становилась примером | Ответ, повторяющий пример дословно, удаляет пример и сам не сохраняется; ответ, обрезанный по `max_tokens` (`finish_reason=length`), примером не становится |
| R2 | Мусорные факты `has_pet: любил`, `likes: любил` по цитате «любимый цвет» | Значение должно совпасть со словом цитаты с учётом окончания, а не только началом: «Казань» ↔ «Казани» да, «любил» ↔ «любимый» нет |
| R3 | `name: Маша` по «ходил с женой Машей»; `works_at: Google` по «в Google меня не взяли» | `name` — только при самопредставлении; факты под отрицанием отклоняются (кроме `dislikes`) |
| R4 | Бэкенд ответил 200 с обрезанным JSON → прокси отдавал клиенту битый JSON | 502 `backend_bad_response` |
| R5 | Если клиент отключался посреди стрима, `await aclose()` мог бросить `CancelledError` до снятия отметки «идёт пользовательский запрос» — фон ждал бы вечно | Отметка снимается до `await`; `/health` показывает `background.waiting_for_user_requests` |
| R6 | Промежуточная версия исправления B5 не давала служебным запросам вытеснять фон — заголовок чата ждал за извлечением фактов до 3 минут | Служебные запросы снова вытесняют фон; извлечение не теряется благодаря повтору (a) |
| R7 | `GET /` → 404, `/health` не говорил, жива ли модель | `GET /` описывает сервис; `/health.backend.reachable` |

### Не исправлялось

- **Картинка без mmproj.** llama.cpp отвечает 500 «image input is not supported… provide the mmproj»; прокси передаёт это как есть — текст понятный.
- **Ролевые игры.** Факты о персонаже пользователя в SillyTavern («я Игорь, кузнец из деревни») сохраняются как факты о пользователе. Разделять персонажа и человека — отдельная задача.
- **Голосовые шаблоны Open WebUI** (голосовой ассистент, TTS-рендерер) в список служебных не добавлены и не проверялись. Если они попадают в память, маркер можно добавить через `SERVICE_PATTERNS` / `SERVICE_SYSTEM_PATTERNS`.
- **Качество ответов 0.5B.** Модель иногда отвечает по-английски или игнорирует память; это свойство модели, прокси отдаёт ей память корректно (проверено перехватом запроса к бэкенду).

## Заметки о прогоне

- На 2 ГБ RAM Qwen2.5-1.5B вместе с двумя экземплярами прокси вытесняет веса модели из page cache: генерация падает с ~10 до 1 токена/с, фоновое извлечение занимает минуты. С одним прокси или с 0.5B — норма (~25 токенов/с). Это ограничение стенда, а не прокси, но стоит помнить: прокси с моделью эмбеддингов занимает ~300 МБ.
- Зонд — `ux_probe.py` (вне репозитория): сценарии `onboarding basic sdk memory owui commands continuity tasks errors regen st agent vision cli` и `down=<url>`.
