## Найдено и исправлено живым прогоном и регрессом шаблонов
1. Прогрев шёл без `tools` → у всех шаблонов, рендерящих инструменты в начало, прогретый префикс не совпадал (кэш пропадал).
2. Извлечение фактов без `max_tokens`: малая модель в JSON-режиме зацикливалась и 300 с держала единственный слот → пользователь получал 502. Теперь `EXTRACT_MAX_TOKENS` и извлечение через BackgroundGate.
3. Recall цеплял одни и те же фрагменты к каждому вопросу по общим словам (+300 токенов/ход). Теперь только слова, которых модель не видит, snippet вокруг совпадения, без повторов.
4. Резерв головы эпохи «по максимуму» сжимал окно до одного хода при малом бюджете → эпоха менялась каждый ход. Теперь по фактическому размеру.
5. Мусорное саммари («0») принималось → теперь фолбэк.
6. `COMPRESS_AT=0` при неизвестном лимите давал бюджет 256.
7. CI smoke ждал `ci-user` в `/facts` — в single-режиме это `default`.
