## Аудиты и проверки
- [Регресс v5.0.0](audit/v5.0.0-regression.md) — тесты по этапам, 32 шаблона llama.cpp, живой прогон, дефекты, найденные и исправленные до релиза.
- [Аудит v4.7.2](audit/v4.7.2-audit.md) — безопасность, приватность, корректность памяти, производительность, Docker/CI, зависимости; таблица «где закрыта каждая находка».
- [Повторный аудит v4.7.3](audit/v4.7.3-recheck.md) — проверка исправлений, новые находки (CSRF, DNS rebinding, регрессии команд и классификатора), патч, ставший v4.7.4.
- [`audit/poc/`](audit/poc/) — вывод PoC-прогонов на v4.7.2, v4.7.3, v4.7.4 и v4.8 (режимы `global1`, `global0`, `auth`).

Аудиты — исторические документы: номера строк и цитаты кода относятся к проверявшейся версии.
